## 0. 验收总原则
- **不接受"仅功能可运行 / CI 通过"作为完成依据**：每项必须附真实证据（截图 / 脚本输出 / URL）。
- 未达标项必须**如实记录为剩余问题**，禁止伪称完成（PROMPT §15）。
- 证据统一归档：`blender/renders/`（A 级）、`tests/visual/`（B 级）、报告 `docs/`。

## H. 最终验收结论（PROMPT §16）

> **最终成果必须是可探索、可交互、可继续编辑和扩展的真实三维项目，而不是单张静态渲染图。**

- [ ] A–G 组 **P0 项全部通过**；
- [ ] 附：完整可运行 Three.js 项目、全部 `.blend` 源文件、bpy 脚本、GLB 资产、资产清单与来源索引、本地运行步骤、测试代码、Blender 预览截图、浏览器最终截图、性能与视觉结果、已知问题清单、真实性与近似说明（PROMPT §15）。
- [ ] 输出 **VERDICT**：`PASS` / `PASS WITH ISSUES`（附剩余问题清单）/ `FAIL`（附阻断项）。
