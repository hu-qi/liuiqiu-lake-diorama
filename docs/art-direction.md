# 华为练秋湖数字沙盘 · 美术方向（docs/art-direction.md）

> 本文件定义**视觉品质基线与验收口径**。所有建模、材质、光照、后处理决策以此为准。
> 视觉关键词直接取自 `PROMPT §1`，不得偏离。

---

## 1. 视觉定位

**一句话**：一座由专业建筑模型师手工制作的研发园区实体微缩沙盘——不是城市规划示意图，也不是照片写实渲染。

### 1.1 关键词（PROMPT §1）
`Premium Architectural Diorama` · `Detailed Miniature Architecture` · `Orthographic Isometric Camera` · `Handcrafted Architectural Model` · `Stylized Realism` · `Procedural Architecture` · `Physically Based Rendering` · `Soft Global Illumination` · `Warm Afternoon Sunlight` · `High Quality Geometry` · `Elegant Landscaping` · `Interactive Digital Twin Inspired Scene`

### 1.2 气质坐标
| 维度 | 目标区间 | 禁忌 |
| --- | --- | --- |
| 饱和度 | 低饱和（水体/植被/墙体均降饱和） | 高饱和霓虹、赛博朋克 |
| 色温 | 温暖午后（暖白日光 ~5000–5600K 观感） | 冷蓝夜景、镜面玻璃城市 |
| 写实度 | Stylized Realism（真实比例 + 适度简化） | 过度照片写实、纯卡通 |
| 明暗 | 软阴影 + 适度 AO，不过曝 | 硬边强反差、过曝死白 |
| 背景 | 浅米灰色（`#E8E4DC` 附近） | 深黑/深蓝背景 |

**明确禁止**：赛博朋克、霓虹灯、镜面玻璃城市、过于鲜艳的卡通效果（PROMPT §9.4）。

## 2. 视觉质量分级标准（L0–L3，PROMPT §1）

| 等级 | 判定条件（全部满足） | 允许用途 |
| --- | --- | --- |
| **L0** | 仅简单基本体（box/cylinder），无屋顶区分、无立面 | 仅程序验证，**不得最终交付** |
| **L1** | 有独立屋顶 + 建筑体量 + 街区结构 | 不得声明完成 |
| **L2** | 在上述基础上，具备**真实三维细节**：窗框、门厅、檐口、山墙、台阶、栏杆中至少 4 类 | 普通背景建筑**下限** |
| **L3** | 具备独特建筑语言 + 精细材质 + 完整环境 + 合理光影；近景可辨材料与构造 | 关键建筑**必须** |

### 2.1 等级分配（本项目的强制映射）
| 对象 | 最低等级 |
| --- | --- |
| A 区制高点塔楼 | **L3** |
| D 区学院主体楼 + 塔楼 | **L3** |
| 三座桥梁（月亮/彩虹/拱桥） | **L3**（结构真实性） |
| 湖景胶囊会议中心 | **L3** |
| 列车车头 + 车厢 | **L3** |
| 各组团标志性建筑 | **L2 起，主楼 L3** |
| 普通背景建筑 | **L2** |
| 植物 / 栏杆 / 路灯等可重复装饰 | 允许优化后的低面数模型（但形态须可辨、须有种类变化） |

> **禁止**把 L0 或 L1 直接声明为完成（PROMPT §1）。
> **禁止**仅通过深色平面贴片代替所有建筑细节（PROMPT §3.4）。

## 3. 建模细节要求

### 3.1 几何真实性
- 桥梁拱洞使用**真实几何挖空**（布尔或合理拓扑），**桥洞不能是黑色半圆贴图**（PROMPT §3.4 / §5.4）。
- 屋顶必须具有**真实厚度与坡面**；不允许单面片。
- 窗框、檐口、台阶在**近距观察时有几何层次**。
- 适度倒角（Bevel），使模型在光照下呈现真实微缩建筑的**边缘高光**（PROMPT §9.2）。
- 建筑比例统一：**禁止随意拉伸导致窗、门、层高失真**（PROMPT §4.7）。

### 3.2 细节预算原则
- 近景关键建筑：**主要轮廓用实际几何**体现；微小浮雕与砖缝可用**法线贴图**。
- 不得为节省面数牺牲建筑最关键的外观轮廓。
- 建筑后高前低、疏密有序；湖泊与建筑体量关系协调；整体轮廓在默认视角下清晰（PROMPT §1）。

### 3.3 树木与景观（PROMPT §9.3）
- 至少 **5 类树木**资产（如：阔叶乔木、针叶/松、灌木球、花树、绿篱），形态与配色可区分。
- 通过**批量实例化 + 随机缩放 + 颜色变化**形成自然园林；**统一随机种子**保证可复现。
- **禁止**大量完全一致的绿色球体。
- 景观丰富但有序，**不得过密遮挡湖泊与视觉焦点**。

## 4. 材质与光照

### 4.1 材质（PBR / Principled BSDF，PROMPT §9.1）
| 材质族 | 目标表现 |
| --- | --- |
| 石材 | 中高粗糙度，微色彩变化，接缝可法线 |
| 砖墙 | 颜色变化（非纯色），粗糙 |
| 陶瓦 | 暖红/赭石，粗糙，瓦垄可法线 |
| 玻璃 | 半透/低反射，避免镜面死亮 |
| 金属栏杆 | 中等金属度 + 粗糙度，非镜面 |
| 木质长椅 | 暖木色，粗糙，纹理可法线 |
| 石桥表面 | 湿感弱反射 + 粗糙 |
| 车厢涂装 | 低饱和涂装 + 金属件 |

- Blender 侧**避免复杂且无法正确导出 glTF 的专有节点网络**；必要时**烘焙为贴图**。
- 运行时由 `src/materials/pbrPresets.ts` 统一调优，避免逐模型随意改材质参数。

### 4.2 光照（PROMPT §8.1 / §9.4）
- 环境光（`AmbientLight` / `HemisphereLight`）+ 方向光（`DirectionalLight`）模拟**温暖午后阳光**。
- **软阴影**（PCFSoft + 合理 shadow bias），适度环境遮蔽。
- 色调映射 `ACESFilmicToneMapping`，色彩空间 `SRGBColorSpace`。
- **不过曝**：高光不溢出为纯白；阴影保留细节不死黑。
- 可选阴影等级（off / low / high），移动端可降级。

### 4.3 构图（PROMPT §8.4）
- **正交等距相机（Orthographic Isometric）**，三分之四视角。
- 默认构图必须**完整展示**：底座 / 湖泊 / 主要建筑组团 / 特色桥梁 / 园区列车。
- 提供**自动适配**：按场景 Bounding Box 计算视距与正交视锥，**不裁切底座**。

---

## 5. 水体美术（PROMPT §5.1）
- 自然不规则轮廓，清晰湖岸边界。
- **低饱和蓝绿色**水体，轻微动态波纹，柔和反射（非镜面）。
- 湖面与桥梁正确衔接（桥洞透出水面，不穿帮）。
- 水体动态由 Three.js 负责；静态岸线/石岸可由 Blender 建模。

---

## 6. 环境氛围与背景
- 场景背景 **浅米灰**（约 `#E8E4DC`），突出暖色调沙盘本体。
- 氛围：温暖午后、低饱和、柔和阴影、适度 AO（PROMPT §9.4）。
- 后处理**克制**：可轻微 Bloom/暗角，但**不得**引入霓虹或强风格化滤镜。

## 7. 美术验收口径（可核验）

| 检查项 | 通过条件 | 证据 |
| --- | --- | --- |
| 等级达标 | 关键建筑 L3、普通建筑 ≥L2 | manifest `fidelityLevel` + 近景截图 |
| 无盒子堆砌 | 默认视角下建筑形态可区分、有屋顶/立面层次 | 全景截图 |
| 桥洞真实 | 拱洞开口可透视（非贴图） | 桥侧近景截图 |
| 湖泊焦点 | 湖泊未被遮挡，为视觉中心 | 默认视角截图 |
| 列车正确 | 车厢独立、姿态沿轨、无穿模 | 列车运行截图 |
| 光照自然 | 不过曝、阴影柔和 | 截图 + 直方图观察 |
| 植物自然 | ≥5 类、有变化、不过密 | 景观截图 |
| 比例统一 | 窗/门/层高无失真拉伸 | 近景截图 |

> **优化不得以删除窗户/桥梁细节/立面为代价**（PROMPT §10）；必须提供优化前后视觉对比（PROMPT §11 / Phase 7）。
