# 华为练秋湖数字沙盘 · 参考资料索引（docs/references.md）

> 本文件是参考资料目录与来源索引，对齐 `PROMPT §2 参考资料与真实性`。
> **纪律：禁止伪造参考文件。** 无下载权限时只记录原始 URL 与人工观察结果，不生成虚假图片或虚假特征描述。

## 0. 采集与记录原则

1. **来源标注**：每条记录必须含 —— 来源 URL / 拍摄或发布信息（可获得时）/ 所属片区 / 主要建筑特征 / 可用于建模的几何信息 / 可信度。
2. **不伪造**：未实际下载/解析的条目，明确标注「仅人工观察 / 待核验」，不得编造正文或几何数据。
3. **版权**：未经授权的照片**不得**直接作为网页资产发布（PROMPT §2）。仅作建模参考。
4. **本地目录**（PROMPT §2）：可合法使用的参考图存入对应目录并制作来源索引：
   ```
   references/
     site-plan/     # 总平面 / 园区地图
     architecture/  # 建筑风格与立面
     bridges/       # 月亮桥 / 彩虹桥 / 拱桥
     train/         # 小火车与轨道
     landscape/     # 景观 / 花园 / 水体
     materials/     # 材质参考（石材/砖/瓦/玻璃/金属/木）
   ```

## 4. 单张参考图元数据模板

在 `references/<类别>/<name>.md` 或索引表中，每张参考图记录：
```yaml
sourceUrl: ""            # 原始 URL（必填）
publishInfo: ""          # 拍摄/发布信息（可获得时）
district: ""             # 所属片区：A–H / BRIDGE / TRAIN / LANDSCAPE / MATERIAL
buildingFeatures: ""     # 主要建筑特征
geometryInfo: ""         # 可用于建模的几何信息（比例、层数、屋顶形制、开窗节奏…）
credibility: ""          # 可信度：高 / 中高 / 中 / 低（+ 依据）
localFile: ""            # 本地合法留存文件路径（无则填 null）
status: ""               # 待核验 / 已核验（含截图）
```
