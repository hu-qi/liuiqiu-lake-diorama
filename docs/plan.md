## 0. 文档说明与交付原则

### 0.1 本计划的地位
本文件是团队并行开发的**进度基线与验收锚点**。每个阶段只有在其「成功标准」被**真实运行证据**（截图 / 脚本输出 / URL）证明后，才允许把状态改为「已完成」。

### 0.2 不可妥协的交付原则（源自 PROMPT §0 / §12 / §15）
1. **三维品质优先、真实运行优先、参考资料准确优先。** 禁止把几何方盒子 + 文字标签当成建筑复刻。
2. **不接受"仅功能可运行 / CI 通过"作为完成依据。** 每项交付必须附：
   - 真实代码文件路径；
   - 资产文件路径（`.blend` 源文件 + `.glb` 运行时资产）；
   - 运行证据（Blender 多角度预览截图 + Three.js 浏览器真实截图）；
   - 剩余问题清单。
3. **两级截图闭环（PROMPT §11.3）**：A. Blender 模型预览；B. Three.js 浏览器截图。两者都通过才算资产完成。
4. **矢量失败也要如实标记**：因缺照片 / 授权 / 工具不可用而无法达标的资产，必须在 manifest 中标记 `verified=false` 及原因，禁止伪称完成（PROMPT §15 收尾）。
5. **禁止占位几何体替代最终资产，禁止降低核心模型的三维品质。**

### 0.3 视觉等级定义（PROMPT §1）
| 等级 | 定义 | 用途 |
| --- | --- | --- |
| L0 | 简单基本体，仅验证程序 | **不得作为最终交付** |
| L1 | 独立屋顶 + 建筑体量 + 街区结构 | 不得声明为完成 |
| L2 | 窗框/门厅/檐口/山墙/台阶/栏杆等真实三维细节 | 普通背景建筑**下限** |
| L3 | 独特建筑语言 + 精细材质 + 完整环境 + 合理光影 | 关键建筑**必须达标** |

### Phase 0：环境与参考资料

- **交付物**：
  - `docs/plan.md`、`docs/architecture.md`、`docs/art-direction.md`、`docs/asset-pipeline.md`、`docs/references.md`、`docs/acceptance.md`；
  - 环境检查结果记录（Blender 版本、MCP 工具清单、Node/npm 版本、`bpy` 可用性）；
  - `references/*/` 目录骨架与来源索引。
- **成功标准**：
  1. `blender --version` 与 MCP `get_addon_status` 返回真实结果（或明确记录"不可用 + 替代方案"）；
  2. `node -v` / `npm -v` 可用；
  3. 6 份 docs 文件齐备且交叉一致；
  4. 6 类参考来源 URL 已登记，未下载者标记"仅人工观察/待核验"（**禁止伪造参考文件**）。
- **测试**：脚本 `scripts/check-env.sh` 输出各工具版本；人工核对 MCP 工具清单快照。

- **交付物**：8 个组团 `.blend` 源文件与 GLB，覆盖：

  - B 水镇（低层临水建筑/屋脊山墙挑檐/木石细部/水街河道/临水平台）；
  - C & H 城市经典轴线（规整办公建筑/对称立面/柱廊/景观轴线/正式庭院/连续檐口，**C/H 保留各自资产身份**）；
  - D 城市大学院落（主体楼 + 两翼 + 开放庭院 + 门廊拱廊 + 塔楼 + 坡屋顶 + 老虎窗，**主体楼与塔楼须 L3**）；
  - E 森林小镇（低密度林间建筑/坡屋顶/树围庭院/步行路径）；
  - F 广场小镇 / 港湾小镇（开放广场/临水步道栏杆/主体立面/喷泉/树阵，**禁止空白铺地**）；

- **成功标准**：
  1. 关键建筑 L3、普通建筑 ≥ L2；

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Blender MCP 不可用 | 无法实时交互建模 | 退回本地 `blender --background --python` 批处理，并**记录真实执行方式**；不得假装 MCP 调用成功 |
| 资产面数过高导致低帧 | 性能不达标 | 早期即用 `gltf-transform inspect` 监控，按 LOD/Draco 压缩；但不得删细节换性能 |
| 坐标轴转换错误（Z-up→Y-up） | 模型朝向/落地错乱 | 统一在 GLB 导出处理轴向，**禁止在加载函数里逐模型加补偿旋转**（见 architecture.md §3） |
| 参考资料不可下载 | 建模失真 | manifest 标记 `verified=false` + `sourceReferences` 记 URL，页面标注"艺术化近似" |
| 列车脱轨/穿模 | 视觉硬伤 | 单一轨道曲线数据源 + 按弧长采样；弯道专项测试 |

## 6. 总体验收标准（对齐 PROMPT §16）

默认视角下必须同时看到：完整厚底座 / 中央练秋湖 / 七种建筑主题 / 八个编号组团 / 高地·学院·城市街区·水镇·森林·广场 / 月亮桥·彩虹桥·拱桥 / 湖景胶囊会议中心 / 带轨道与车站的小火车 / 丰富有序的景观植物 / 柔和自然阳光与阴影。

近距离观察：建筑有窗框、檐线、屋顶坡度、山墙、台阶、栏杆；桥梁有真实开放孔洞；列车有独立车厢与正确运行姿态。

> **最终成果必须是可探索、可交互、可继续编辑和扩展的真实三维项目，而不是单张静态渲染图。**

逐项验收方式见 `docs/acceptance.md`。
